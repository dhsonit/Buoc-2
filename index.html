Tải Công Cụ Trải Nghiệm (Bước 2)

Vui lòng tải và cài đặt theo đúng thứ tự 2 file APK bên dưới về điện thoại Android của bạn.

1. Tải MicroG (Cài Đặt Trước) 2. Tải Ứng Dụng YouTube (Đã Vá)
Hướng dẫn nhanh:
  1. Cài đặt file MicroG trước để hỗ trợ đăng nhập tài khoản.
  2. Tiếp theo cài đặt file YouTube.
  3. Mở ứng dụng vừa cài và đăng nhập tài khoản để sử dụng bình thường.
